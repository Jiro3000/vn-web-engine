# Windows Media decoder

This module decodes the Windows Media codecs of ASF movies, which browsers cannot play:
WMV3 (Windows Media Video 9, Simple and Main profile) video and WMA Standard (0x161),
WMA Pro (0x162) and WMA Lossless (0x163) audio. `src/video/windows-media.ts` wraps it as
`WindowsMediaDecoder`, and `src/formats/asf/movie.ts` combines it with the ASF demuxer
(`src/formats/asf/demux.ts`) into a `MovieStream`. Fullscreen ASF movies therefore play
through the same decode worker, audio clock and WebGL YUV renderer as other software
movies.

## Contents

- `bridge.c` is a small C API over libavcodec. Each handle wraps one decoder. `wm_send`
  takes one complete ASF media object with its presentation time in milliseconds, and an
  empty send drains the decoder. `wm_receive` returns the next picture or audio frame.
  Pictures are planar 8-bit 4:2:0. Audio is converted to planar float, scaling 16-bit and
  32-bit integer samples by 2^-15 and 2^-31. libavcodec logging is disabled.
- `vendor/` holds the subset of FFmpeg 7.1.1 (libavcodec and libavutil) that the bridge
  links. It contains the sources the linker keeps, the headers they include and
  `COPYING.LGPLv2.1`. The configuration files `config.h`, `config_components.h`,
  `libavutil/avconfig.h`, `libavcodec/codec_list.c` and `libavcodec/bsf_list.c` are
  generated by FFmpeg's `configure` for this target:

  ```sh
  configure --target-os=none --arch=x86_32 --enable-cross-compile --cc=emcc \
    --disable-everything --disable-programs --disable-doc --disable-network \
    --disable-avdevice --disable-avformat --disable-swscale --disable-swresample \
    --disable-postproc --disable-avfilter --disable-asm --disable-inline-asm \
    --disable-x86asm --disable-pthreads --disable-iconv --disable-zlib --disable-bzlib \
    --disable-lzma --disable-runtime-cpudetect --disable-debug \
    --enable-decoder='wmv3,wmav2,wmapro,wmalossless'
  ```

  The source archive is `ffmpeg-7.1.1.tar.xz` (SHA-256
  `733984395e0dbbe5c046abda2dc49a5544e7e0e1e2366bba849222ae9e3a03b1`). The files are
  unmodified apart from these generated ones.

## Building

`npm run build:windows-media` (`tools/build-windows-media.mjs`) compiles every vendor
source and the bridge with Emscripten (`emcc` on `PATH`) at `-O3 -msimd128`, using the
defines that FFmpeg's build uses. It links a standalone module with no entry point and
growable memory of up to 512 MiB. The result is written to
`src/video/windows-media-wasm-binary.ts` as base64 and is checked in. The module imports
only WASI stubs, which the host provides; nothing uses files, the clock or the
environment.

Generic C replaces FFmpeg's x86 and ARM assembly. Decoding 1920×1080 WMV3 takes about
16–18 ms per frame in Node on Apple silicon, and 1280×720 about 9 ms.
`AsfMovie` is loaded on demand (`openMovieStream` imports it on the ASF signature), so
the 1.2 MB module does not enlarge pages that never play an ASF movie.

## Verification

`tests/asf-windows-media.test.mjs` checks the ASF layout and demuxer on synthetic files,
including split, multiple and compressed payloads. It also decodes a synthetic WMA
fixture (`tests/fixtures/asf/sine-wmav2.wma`, two sine tones) and checks its sample count
and per-channel tone. No WMV3 encoder exists, so video is verified against the native
FFmpeg build outside the suite. Every decoded frame of three 720p and 1080p WMV3 movies
had the same `framemd5` hash, and every movie had the same audio sample count. WMA
Lossless audio was bit-identical. WMA Standard and Pro audio differed by at most 3.6e-7,
from float rounding in the inverse MDCT.
